<div class="answer">
  <p>
    Une <strong>landing page</strong> (ou « page d'atterrissage ») est une page web
    autonome, conçue pour amener un type de visiteur précis vers <strong>une seule
    action</strong> : demander un devis, réserver un appel, s'inscrire, acheter.
    À la différence d'un site classique, elle ne cherche pas à tout présenter :
    elle déroule un argumentaire complet pour une offre, une audience et un
    objectif donnés.
  </p>
</div>

## La définition, mot par mot

Le terme vient de l'anglais *to land* : atterrir. C'est la page sur laquelle
« atterrit » un visiteur qui a cliqué quelque part — une publicité, un résultat
de recherche, un lien dans un email, une publication sociale.

Trois caractéristiques la distinguent d'une page web ordinaire :

- **Un seul objectif.** Toute la page converge vers une action unique. Ce qui
  n'y contribue pas est retiré, y compris souvent le menu de navigation.
- **Une seule audience.** La page s'adresse à un profil de visiteur précis,
  dans son vocabulaire, avec ses objections. Elle assume de ne pas parler à
  tout le monde.
- **Un argumentaire ordonné.** Les sections se succèdent dans l'ordre des
  questions que se pose le visiteur : de quoi s'agit-il ? est-ce pour moi ?
  puis-je y croire ? que se passe-t-il si je clique ?

## Landing page, page d'accueil, site vitrine : qui fait quoi

La confusion est fréquente, et elle coûte cher : on demande souvent à une page
d'accueil de faire le travail d'une landing page — elle y échoue presque
toujours.

| | Landing page | Page d'accueil | Site vitrine |
|---|---|---|---|
| **Objectif** | Une action unique | Orienter vers le bon contenu | Présenter l'ensemble de l'activité |
| **Audience** | Un segment précis | Tous les publics | Tous les publics |
| **Navigation** | Réduite au minimum | Complète | Complète |
| **Trafic type** | Campagnes, liens ciblés | Recherches de marque | Recherches variées |
| **Se mesure par** | Taux de conversion | Clics vers les sections | Contacts et notoriété |

Les deux dispositifs sont complémentaires : un site vitrine installe la
crédibilité générale, la landing page transforme un trafic précis en demandes.
Beaucoup d'activités ont besoin des deux — certaines n'ont besoin que d'une
bonne landing page pour commencer.

## Quand une landing page devient indispensable

Quatre situations la justifient presque toujours :

1. **Une campagne payante.** Chaque clic facturé mérite une page qui poursuit
   exactement la promesse de l'annonce. Envoyer du trafic payant vers une page
   d'accueil générique, c'est financer des visites sans suite.
2. **Un lancement.** Offre nouvelle, produit nouveau, activité nouvelle : la
   landing page fonde la crédibilité et collecte les premiers contacts, avant
   même qu'un site complet existe.
3. **Une offre phare à isoler.** Quand une prestation mérite son propre
   argumentaire, la noyer dans un menu « Services » revient à la cacher.
4. **Un événement ou une échéance.** Webinaire, formation datée, ouverture de
   session : une page dédiée, un objectif, un compte à rebours naturel.

À l'inverse, une landing page n'est pas la bonne réponse quand le problème est
ailleurs : offre encore floue, absence totale de trafic, cible introuvable. Une
page, même excellente, ne convertit que le trafic qu'on lui apporte.

## De quoi se compose une bonne landing page ?

Une structure éprouvée existe — non comme un template à recopier, mais comme
une suite de questions à traiter dans le bon ordre : promesse, démonstration,
preuve, objections, action. Elle est détaillée section par section dans
[l'anatomie d'une landing page qui convertit](/guide/anatomie-landing-page/).

La qualité d'exécution fait ensuite l'écart : le même plan produit une page
banale ou une page qui convertit, selon le travail de
[message, de design et de technique](/methode/) investi. C'est aussi ce qui
explique les écarts de prix du marché, décryptés sur
[la page tarifs](/tarifs/).

## Trois idées reçues à écarter

**« C'est une page vite faite. »** C'est l'inverse : concentrer une décision
sur une page unique exige plus de travail stratégique qu'étaler du contenu sur
dix pages. La brièveté se paie en précision.

**« Il faut absolument qu'elle soit courte. »** La bonne longueur est celle de
l'argumentaire : une offre simple à faible engagement se défend en trois
sections ; une prestation coûteuse peut exiger une page longue qui traite
chaque objection. On mesure la longueur en questions traitées, pas en écrans.

**« Le design fait la conversion. »** Le design y contribue — hiérarchie,
confiance, lisibilité — mais il met en scène un message. Si le message ne
tranche rien, la mise en scène n'a rien à montrer.
